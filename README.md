# 🌍 TerraNova

**TerraNova** es una aplicación móvil desarrollada en **Android (Kotlin)** diseñada para realizar el cálculo de áreas, perímetros y tasación/valorización de precios de terrenos (urbanos y rústicos).

## 📱 Características Principales
- **Cotización de Terrenos:** Cálculo automático de áreas ($m^2$), perímetros y montos totales según el precio por metro cuadrado.
- **Navegación Fluida:** Implementada con Jetpack Navigation Component.
- **Interfaz Moderna:** Desarrollada siguiendo los patrones de diseño de Android Studio.

## 🛠️ Tecnologías Utilizadas
- **Lenguaje:** Kotlin
- **Entorno:** Android Studio
- **Gestor de Dependencias:** Gradle
- **Componentes:** Android Jetpack (Navigation)
